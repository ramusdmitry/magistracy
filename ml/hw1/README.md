# Домашнее задание №1: Регрессия с инференсом

## Краткое описание выполненной работы

В данном дз была выполнена полная предобработка данных о продаже автомобилей, проведен EDA, обучены различные модели регрессии и создано интерактивное приложение на Streamlit.

## Этапы работы

### 1. EDA и обработка признаков

#### Базовый EDA
- Проведен анализ пропущенных значений в данных
- Обнаружены пропуски в признаках: `mileage`, `engine`, `max_power`, `torque`, `seats`
- Найдено 1170 явных дубликатов в объединенном датасете
- Построен дашборд с помощью ydata-profiling

#### Обработка пропусков
- Заполнены пропуски в числовых признаках медианами (рассчитанными на train)
- Заполнены пропуски в категориальных признаках модой (самым частым значением)
- Все пропуски успешно устранены

#### Удаление дубликатов
- Удалены объекты с одинаковым признаковым описанием (оставлена первая запись)
- Размер тренировочного набора уменьшился с 6999 до 5840 строк

#### Преобразование признаков
- Убраны единицы измерения из признаков `mileage`, `engine`, `max_power`
- Приведены типы данных к числовым (`float`)
- Удален столбец `torque` для упрощения задачи
- Приведены столбцы `engine` и `seats` к типу `int`

#### Статистический анализ
- Проанализированы распределения числовых и категориальных признаков
- Подтверждена схожесть распределений на train и test, что говорит о корректном разделении данных

### 2. Визуализации

#### Pairplot анализ
- Построены pairplot для train и test данных
- Выявлены связи признаков с целевой переменной:
  - `year` - положительная корреляция (новее = дороже)
  - `max_power` - сильная положительная корреляция
  - `km_driven` - отрицательная корреляция (больше пробег = дешевле)
- Подтверждена схожесть распределений на train и test

#### Корреляционный анализ
- Построена тепловая карта корреляций
- Наиболее скоррелированные признаки: `max_power` и `selling_price` (r=0.69), `engine` и `max_power` (r=0.68)
- Наименее скоррелированные: `year` и `engine` (r≈0.00)

#### Бонусные визуализации
- Распределение целевой переменной в обычной и логарифмической шкале
- Зависимость цены от года выпуска по типам топлива
- Визуализация корреляций признаков с целевой переменной

### 3. Модели только на вещественных признаках

#### Линейная регрессия
- **Train R²**: 0.5923, **Train MSE**: 116,874,153,930
- **Test R²**: 0.5941, **Test MSE**: 233,298,779,730
- Вывод: Модель показывает умеренное качество, небольшой разрыв между train и test указывает на отсутствие переобучения

#### Стандартизация признаков
- Применена стандартизация признаков (StandardScaler)
- Наиболее информативный признак: `max_power` (наибольший по модулю коэффициент)

#### Lasso регрессия
- С параметрами по умолчанию не занулила веса (все признаки важны)
- После GridSearchCV лучший параметр: `alpha=100`
- Качество практически не изменилось по сравнению с обычной линейной регрессией

#### ElasticNet регрессия
- Лучшие параметры: `alpha=1`, `l1_ratio=0.9`
- Всего обучено 250 моделей (5 альфа × 5 l1_ratio × 10 фолдов)
- **Test R²**: 0.5722 (несколько хуже, чем Lasso)

### 4. Модели с категориальными признаками

#### Предобработка категориальных признаков
- Извлечена марка автомобиля из столбца `name` (первое слово)
- Применено target encoding для марки (средняя цена по марке)
- Удален исходный столбец `name`

#### OneHot-кодирование
- Закодированы категориальные признаки: `fuel`, `seller_type`, `transmission`, `owner`
- Также закодирован признак `seats` как категориальный
- Использован параметр `drop='first'` для избежания мультиколлинеарности

#### Ridge регрессия
- Лучший параметр регуляризации: `alpha=100`
- **Train R²**: 0.7024, **Train MSE**: 85,293,990,963
- **Test R²**: 0.6681, **Test MSE**: 190,808,938,140
- **Вывод**: Добавление категориальных признаков значительно улучшило качество модели (R² вырос с ~0.59 до 0.67)

## Результаты и метрики

### Сравнение моделей по R² на тесте:
1. **Ridge с категориальными признаками**: 0.6681 ⭐ (лучшая)
2. **ElasticNet**: 0.5722
3. **Lasso (best)**: 0.5940
4. **Linear Regression**: 0.5941

### Бизнес-метрика
Доля прогнозов, отличающихся от реальных цен не более чем на 10%:
- **Ridge_categorical**: 24.6% ⭐ (лучшая)
- **ElasticNet**: 24.1%
- **LinearRegression/Lasso**: ~22.7%

## Что дало наибольший прирост качества

1. **Добавление категориальных признаков** - самый значительный прирост качества (R² вырос с 0.59 до 0.67)
2. **Применение Ridge регуляризации** - помогло избежать переобучения при большом количестве признаков
3. **Предобработка признака `name`** - извлечение марки и target encoding добавили полезную информацию

## Что сделать не удалось и почему

- Не удалось значительно улучшить качество с помощью Lasso регуляризации - все признаки оказались важными, зануления весов не произошло
- ElasticNet показал результаты хуже, чем ожидалось - возможно, требуется более тонкая настройка гиперпараметров
- Бизнес-метрика показывает, что даже лучшая модель правильно предсказывает цену с точностью ±10% только для ~25% автомобилей - это указывает на сложность задачи и возможные выбросы в данных

## Оценка разработанного сервиса

### Удобство использования
- Приложение имеет интуитивно понятный интерфейс с тремя вкладками
- Поддерживается два способа ввода данных: ручной ввод и загрузка CSV файла
- Результаты отображаются в удобном формате

### Визуализации
**Что получилось хорошо:**
- Корреляционная матрица наглядно показывает связи между признаками
- Графики распределений помогают понять структуру данных
- Визуализация весов модели позволяет интерпретировать важность признаков

**Что получилось менее удачно:**
- Pairplot может быть перегружен при большом количестве признаков
- Некоторые графики требуют прокрутки для полного просмотра

### Ограничения и проблемы
1. Приложение требует предварительного запуска `save_model.py` для создания модели
2. Нет валидации входных данных - при некорректных значениях может возникнуть ошибка
3. Отсутствует обработка неизвестных категориальных значений (хотя используется `handle_unknown='ignore'`)

### Планируемые улучшения
1. Добавить валидацию входных данных с понятными сообщениями об ошибках
2. Реализовать автоматическое создание модели при первом запуске приложения
3. Добавить возможность сравнения нескольких моделей
4. Улучшить визуализацию предсказаний (например, показать доверительные интервалы)
